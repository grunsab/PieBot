# Archived documents

Plans, runbooks and handoffs from earlier PieBot campaigns. They are kept for
provenance: the evidence files and commit history refer to them. They are
superseded by the README and the current guides in `documents/`, and their
paths, hosts and numbers are no longer current.

| File | Date | What it was |
|------|------|-------------|
| `ZEN5_3090_NNUE_SETUP.md` | 2026-02 | Ubuntu setup guide for the original self-play NNUE pipeline on a Zen 5 + RTX 3090 box |
| `PostDeadlineBattery.md` | 2026-08 | Runbook for the measurements taken after the 72-hour self-play training run |
| `CampaignPlan_SuperGM_v1.md` | 2026-08 | Plan for the self-play "super-GM" training campaign; its goal was later revised |
| `LCZeroTraining.md` | 2026-09-07 | Setup and restart notes for the first LCZero-data training run (arch-v2 net) |
| `agent_handoffs_2026.md` | 2026-08 to 2026-10 | The `AGENTS.md` and `CLAUDE.md` working logs, preserved verbatim before they were rewritten |
